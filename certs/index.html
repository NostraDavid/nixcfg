Installeer deze publieke CA-certificaten op je apparaat om de certificaten van Forgejo en FreeIPA te vertrouwen.

CA al geïnstalleerd? Gebruik de beveiligde HTTPS-versie van deze website. De HTTP-versie blijft bereikbaar voor de eerste installatie. HTTPS wordt pas vertrouwd nadat de Forgejo-CA in je systeem of browser is geïnstalleerd.

Installeren op je apparaat

  1. Download het benodigde certificaat en controleer de fingerprint.
  2. Android: zoek in Instellingen naar certificaten installeren en kies CA-certificaat. De menunamen verschillen per toestel. Sommige apps vereisen een eigen CA-import. Pak de ZIP eerst uit en installeer de twee CA's afzonderlijk.
  3. Debian: volg de terminalcommando's hieronder om beide CA's uit de nieuwste bundel te installeren.
  4. NixOS: de gedeelde PowerLAN-configuratie bevat beide CA's. Activeer de bijgewerkte configuratie op je machine.

Debian en Firefox: installeren via de terminal

Kopieer dit hele blok in een Bash-terminal als je eigen gebruiker. Het installeert de hulpmiddelen, downloadt de ZIP en beide .crt-bestanden naar ~/Downloads, werkt de certificaatopslag van Debian bij en laat je een Firefox-profiel kiezen. Je hebt sudo-rechten nodig; de Firefox-import gebeurt zonder sudo.

Het blok pauzeert nadat het beide fingerprints heeft getoond. Vergelijk die via een onafhankelijk, vertrouwd apparaat of je beheerder voordat je ja typt. De checksum van dezelfde HTTP-server controleert de overdracht, niet de identiteit van de CA.

Het keuzemenu toont bestaande profielen onder ~/.mozilla/firefox, de standaardmap van Firefox en Firefox ESR op Debian. Kies een profielnummer of sla de Firefox-import over. Gebruik je meerdere profielen, voer het blok dan opnieuw uit voor ieder gewenst profiel. Aangepaste profielmappen en Snap- of Flatpak-installaties worden niet automatisch gevonden. 

bash <<'POWERLAN'
set -euo pipefail

sudo apt-get update
sudo apt-get install -y ca-certificates curl unzip openssl libnss3-tools
mkdir -p "$HOME/Downloads"
cd "$HOME/Downloads"

bundle_url=$(curl -fsSL -o powerlan-ca.zip -w '%{url_effective}' http://192.168.2.111/powerlan-ca-latest.zip)
curl -fsSL -o powerlan-ca.zip.sha256 "$bundle_url.sha256"
sha256sum -c powerlan-ca.zip.sha256
unzip -p powerlan-ca.zip freeipa.crt > freeipa.crt
unzip -p powerlan-ca.zip forgejo-ca.crt > forgejo-ca.crt
openssl x509 -in freeipa.crt -noout -fingerprint -sha256
openssl x509 -in forgejo-ca.crt -noout -fingerprint -sha256

read -r -p 'Vergelijk beide fingerprints via een vertrouwd apparaat. Kloppen ze? Typ ja: ' bevestiging </dev/tty
if [[ "$bevestiging" != ja ]]; then
  echo 'Afgebroken; er zijn geen certificaten geïnstalleerd.'
  exit 1
fi

sudo install -d -m 0755 /usr/local/share/ca-certificates/powerlan
sudo install -m 0644 freeipa.crt forgejo-ca.crt /usr/local/share/ca-certificates/powerlan/
sudo update-ca-certificates
curl --fail https://forgejo.powerlan.empire/api/healthz

firefox_profiles=()
# shortcut: scans ~/.mozilla/firefox only; use profiles.ini if custom profile locations are needed.
if [[ -d "$HOME/.mozilla/firefox" ]]; then
  while IFS= read -r -d '' cert_db; do
    firefox_profiles+=("${cert_db%/cert9.db}")
  done < <(find "$HOME/.mozilla/firefox" -mindepth 2 -maxdepth 2 -type f -name cert9.db -print0 | sort -z)
fi

if (( ${#firefox_profiles[@]} == 0 )); then
  echo 'Debian is bijgewerkt. Geen Firefox-profielen gevonden onder ~/.mozilla/firefox.'
  echo 'Start Firefox eenmaal om een profiel te maken en voer dit blok daarna opnieuw uit.'
  exit 0
fi

PS3='Kies het nummer van je Firefox-profiel: '
firefox_profile=''
select firefox_profile in "${firefox_profiles[@]}" 'Firefox-import overslaan'; do
  case "$firefox_profile" in
    'Firefox-import overslaan') exit 0 ;;
    '') echo 'Kies een geldig nummer.' ;;
    *) break ;;
  esac
done </dev/tty
[[ -n "$firefox_profile" ]] || { echo 'Geen profiel gekozen; Firefox-import afgebroken.'; exit 1; }

read -r -p 'Sluit Firefox volledig af en druk daarna op Enter: ' bevestiging </dev/tty
certutil -A -d "sql:$firefox_profile" -n 'Powerlan FreeIPA CA' -t 'C,,' -i "$HOME/Downloads/freeipa.crt"
certutil -A -d "sql:$firefox_profile" -n 'Powerlan Forgejo CA' -t 'C,,' -i "$HOME/Downloads/forgejo-ca.crt"
certutil -L -d "sql:$firefox_profile" -n 'Powerlan FreeIPA CA'
certutil -L -d "sql:$firefox_profile" -n 'Powerlan Forgejo CA'
echo 'Klaar. Start Firefox opnieuw en open https://forgejo.powerlan.empire/.'
POWERLAN

Sluit Firefox volledig af wanneer het blok daarom vraagt en start het na de import opnieuw. Alleen het tabblad vernieuwen is niet genoeg. De cache- en databasecontrole moeten beide pass melden. Bestaande vertrouwde CA's blijven behouden.

Blijft een waarschuwing staan, noteer dan de exacte foutcode. Schakel certificaatcontrole niet uit. Zie ook de Firefox-instructies voor Linux.
