# Lokale diensticonen

De merkiconen komen uit
[Dashboard Icons](https://github.com/homarr-labs/dashboard-icons), map `svg`. Ze
staan in de repository zodat Homepage tijdens gebruik geen externe CDN hoeft te
bereiken. Merknamen en logo's blijven van hun eigenaren.

`certificate.svg` is een lokaal getekend, algemeen certificaatpictogram.
